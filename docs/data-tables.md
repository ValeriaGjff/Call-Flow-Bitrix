# Required n8n Data Tables

Create these tables in n8n before running the imported workflows.

## `voice_dialog_state`

Suggested columns:

| Column | Type |
|---|---|
| phone | string |
| clientName | string |
| clientType | string |
| city | string |
| transcriptFull | string |
| stage | string |

## `transfer_targets`

| Column | Type |
|---|---|
| phone | string |
| clientType | string |
| assignedExt | string |
| secondaryExt | string |
| fallbackExts | string |

## `lead_duty_queue`

At minimum:

| Column | Type |
|---|---|
| key | string |
| value | string |

The demo workflows use this table to persist the alternating duty turn.

## After import

The public JSON exports cannot know the Data Table IDs generated by another n8n instance. In every Data Table node, select the table you created. Do not try to reuse the placeholder IDs from the JSON.
